# ABTalks AI Interview Agent

AI-powered adaptive technical interviewer for the ABTalks AI Cohort.

## Objective

Build an AI Interview Agent that conducts personalized,
multi-turn technical interviews based on a candidate's
learning journey through the 31-day AI Cohort.

## Core Requirements

- Minimum 8 interview questions
- At least 4 curriculum days
- Adaptive follow-up questions
- Multi-turn conversation context
- Structured final feedback
- POST /api/interview endpoint
